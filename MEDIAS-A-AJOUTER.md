# Médias à ajouter

Copiez vos fichiers dans `dist/assets/` avec exactement les noms ci-dessous. Ils s’afficheront automatiquement à la place des emplacements prévus. Formats et proportions conseillés ; vous pouvez modifier les noms dans `dist/app.js`.

| Page | Emplacement | Nom de fichier | Proportion conseillée |
|---|---|---|---|
| Accueil | Grande image « Montage vidéo » | `accueil-montage.jpg` | portrait, environ 3:4 |
| Accueil | Grande image « Graphisme » | `accueil-graphisme.jpg` | portrait, environ 3:4 |
| Accueil | Grande image « Développement web » | `accueil-web.jpg` | portrait, environ 3:4 |
| Montage vidéo | Vidéo storytelling | `video-storytelling.mp4` | 16:10 ou 16:9 |
| Montage vidéo | Montage simple | `montage-simple.mp4` | 16:10 ou 16:9 |
| Montage vidéo | Publicités complètes | `publicite-complete.mp4` | 16:10 ou 16:9 |
| Graphisme | Miniature 1 | `miniature-01.jpg` | 16:9 |
| Graphisme | Miniature 2 | `miniature-02.jpg` | 16:9 |
| Graphisme | Miniature 3 | `miniature-03.jpg` | 16:9 |
| Graphisme | Planche de logos | `board-logos.jpg` | 16:10 |
| Graphisme | Menu de restaurant 1 | `menu-restaurant-01.jpg` | portrait, 4:5 |
| Graphisme | Menu de restaurant 2 | `menu-restaurant-02.jpg` | portrait, 4:5 |

| Développement web | Aperçu du site 2 | `site-02.jpg` | 16:10 |
| Développement web | Aperçu du site 3 | `site-03.jpg` | 16:10 |

**Liens web :** dans `dist/app.js`, remplacez `https://votre-site-01.fr`, `https://votre-site-02.fr` et `https://votre-site-03.fr` par les vraies adresses. Remplacez aussi les titres et descriptions « Projet web 01/02/03 » par ceux de vos réalisations. Les textes sous les miniatures et les animations se modifient dans `slideSets` du même fichier. Vous pouvez ajouter d’autres diapositives à ces listes.

Le site est initialement privé. Il faudra ouvrir son accès au public quand vous voudrez montrer le portfolio à des clients.
